# M Umar — Portfolio

    npm install
    npm run dev      # http://localhost:3000
    npm run build

- **All text/links/images:** edit `content.ts` (items marked TODO are placeholders).
- **Images:** put files in `public/`, then set `image: "/file.png"` on a project in `content.ts`.
- **Colours/fonts:** CSS variables at the top of `app/globals.css`.
- **Animation engine:** `components/useMotion.ts` (GSAP + Lenis). Elements opt in with
  `data-split`, `data-scrub`, `data-reveal`, `data-stagger`, `data-parallax`, `data-magnetic`, `data-tilt`.
- **Deploy:** push to GitHub and import into Vercel.
